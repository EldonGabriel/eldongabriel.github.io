## Featured Projects

### Windows Defender Hardening (Local GPO)
- Enforced real-time protection and behavioral monitoring using Local Group Policy  
- Restricted user ability to disable or modify security controls  
- Validated enforcement through policy refresh and system testing  
🔗 https://eldongabriel.github.io/hardening-windows-defender-local-gpo/

### Active Directory Disaster Recovery & Identity Restoration
- Rebuilt Domain Controller after full system failure  
- Performed system state recovery using Directory Services Restore Mode (DSRM)  
- Validated replication and directory health using dcdiag and repadmin  
🔗 https://eldongabriel.github.io/active-directory-bare-metal-recovery/

### Enterprise IPsec VPN Diagnostics
- Troubleshot site-to-site VPN tunnel failure using structured analysis  
- Identified misconfiguration impacting secure communication  
- Restored encrypted connectivity between network segments  
🔗 https://eldongabriel.github.io/architecting-enterprise-ipsec-vpns/
