# Overview

<p style="font-size:1.2em; line-height:1.6;">

This enterprise scenario simulates a real-world IT environment. Infrastructure, networking, identity, security, and administration services work together through a structured workflow.

The implementation covers planning, deployment, configuration, hardening, validation, troubleshooting, and documentation.

</p>

<p style="font-size:1.2em; line-height:1.6;">

The scenario demonstrates systems administration practices for deploying, securing, and maintaining enterprise infrastructure. It produces documentation that supports repeatable operations and future system management.

</p>

<p style="text-align:center; font-size:1.05em; color:#fff; background:rgba(255,255,255,0.05); padding:15px; border-radius:8px; margin:30px 0;">

<strong>Focus:</strong> Infrastructure Deployment · Security Hardening · Operational Validation · Enterprise Documentation

</p>

# Scenario Objectives

- Deploy an Active Directory domain controller.

- Configure DNS and DHCP services.

- Join Windows workstations to the domain.

- Apply Group Policy security controls.

- Validate domain operations.

- Troubleshoot configuration issues.

- Produce implementation documentation.

# Environment Summary

| Component | Technology |
|-----------|------------|
| Hypervisor | Oracle VirtualBox 7.x |
| Operating Systems | Windows Server 2022, Windows 10 Pro |
| Identity Services | Active Directory Domain Services (AD DS) |
| Network Services | DNS, DHCP |
| Networking | Internal Network, TCP/IP, ICMP |
| Security Controls | Group Policy, Windows Firewall, Remote Desktop (RDP) |
| Administration Tools | Server Manager, PowerShell, Active Directory Users and Computers |
| Monitoring | Event Viewer, DHCP Lease Manager |
